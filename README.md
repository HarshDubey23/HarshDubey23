## Flagship Work

### [ProctorIQ](https://github.com/HarshDubey23/ProctorIQ)

Privacy-first exam-integrity analytics. MediaPipe and ONNX Runtime Web run
inference in the browser; the backend receives structured events, not video.
The repository includes FastAPI, WebSockets, HMAC-SHA256 report verification,
SQLite persistence, model artifacts, and automated backend/frontend testing.

### [expensetracker](https://github.com/HarshDubey23/expensetracker)

React and Express expense tracking with bcrypt authentication, JWT sessions,
MongoDB persistence, user-scoped queries, Helmet, CORS allowlisting, and a
documented deployment path.

### [DarshanEase](https://github.com/HarshDubey23/DarshanEase)

React and Express temple and darshan booking workflows. This repository is
under active hardening; its README calls out security and feature gaps instead
of presenting unshipped functionality as production behavior.

### [Fraud Detection](https://github.com/HarshDubey23/Credit-Card-Fraud-Detection)

An exploratory scikit-learn notebook retained as a transparent rebuild
candidate. The README explicitly distinguishes the current notebook from a
future reproducible, tested, deployable fraud pipeline.
